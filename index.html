🛠️ 各原型技术说明

  • A3 多智能体学习系统：单文件 HTML + 原生 JS；关键词路由匹配内置知识库，模拟多 Agent 协作与消息转发；Canvas 粒子背景与雷达图；无后端依赖。
  • A5 景区导览数字人：单文件 HTML + 原生 JS；内置桂林景点 / 美食 / 半日·一日·两日路线知识库；数字人表情与口型动效为纯 CSS；语音按钮依赖浏览器麦克风权限（可选，不影响演示）。
  • 知声 · 语音知识图谱：单文件 HTML + 原生 JS；演示模式下页内 mockFetch 拦截全部接口请求并返回内置数据（上传转写延迟 1.5s 模拟真实体验）；接真实后端时将脚本顶部 USE_MOCK 改为 false 并配置 API 地址，详见页面内注释与 README。
